# Mario Kapakodu – veebirakenduse kasutajaliides

Loomade varjupaiga veebirakenduse staatiline kasutajaliides, mis on ehitatud **HTML-i, CSS-i ja Bootstrap 5** abil.
Selles etapis ei kasutata veel PHP-d ega andmebaasi. Dünaamiline funktsionaalsus lisatakse järgmistes peatükkides.

## Vaated

| Fail | Kirjeldus |
|------|-----------|
| `index.html` | Avaleht |
| `all_animals.html` | Kõigi loomade vaade otsingu, filtrite ja lehekülgedega |
| `animal.html` | Looma detailvaade |
| `contact.html` | Kontaktileht |
| `login.html` | Sisselogimise leht |
| `admin/index.html` | Administraatori avaleht |
| `admin/animals.html` | Loomade haldamise vaade |
| `admin/animal_add.html` | Looma lisamise ja muutmise vorm |

- HTML5, CSS3
- Bootstrap 5.3 (CDN)
- Git ja GitHub
